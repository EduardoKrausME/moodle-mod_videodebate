# Video Debate (mod_videodebate)

Video Debate is a Moodle activity for academic debates grounded in evidence from a video. A teacher configures a debate
question and positions. Students choose or receive a position, publish an initial argument with one or more video
evidences, and then reply to classmates.

The activity includes server-authoritative watched-segment tracking, resume, timeline markers, upload/direct
URL/YouTube/Vimeo sources, Moodle groups, publish-before-viewing, weighted grading, completion rules, reports,
backup/restore, privacy API and Moodle gradebook integration.

The player/tracking architecture was designed from and adapted where useful
from `EduardoKrausME/moodle-mod_videoprogress`. Static plugin validation targets the rules
from `EduardoKrausME/moodle-plugin-validate`.

## Requirements

Moodle 4.5 or later (2024042200), PHP supported by that Moodle release.

## Installation

Copy the `videodebate` directory to `mod/videodebate` and visit Site administration > Notifications.
