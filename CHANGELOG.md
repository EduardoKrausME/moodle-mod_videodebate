# Changelog

This changelog documents only the two most recent published GitHub releases. Each entry describes the changes between its release tag and the immediately preceding published release; later changes on `master` are excluded.

## 1.1.6 - 2026-10-15

### Changed

- Added the plugin icon image at `pix/icon.png` and reorganized the SVG logo asset as `pix/monologo.svg`.
- Updated the plugin release identifier from `1.1.5` to `1.1.6` and its build number from `2026101500` to `2026101501`.

No functional changes to the Video Debate activity were identified between the published `1.1.5` and `1.1.6` tags.

[Compare 1.1.5...1.1.6](https://github.com/EduardoKrausME/moodle-mod_videodebate/compare/1.1.5...1.1.6)

## 1.1.5 - 2026-10-15

### Changed

- Updated the GitHub Actions CI database service from PostgreSQL 16 to PostgreSQL 17.
- Updated the MariaDB CI service from version 10 to 11.4, including its initialization environment variables and health-check configuration.
- Updated the plugin release identifier from `1.1.4` to `1.1.5` and its build number from `2026101200` to `2026101500`.

No functional changes to the Video Debate activity were identified between the published `1.1.4` and `1.1.5` tags.

[Compare 1.1.4...1.1.5](https://github.com/EduardoKrausME/moodle-mod_videodebate/compare/1.1.4...1.1.5)
